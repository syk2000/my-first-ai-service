재질 · 경도 · 표면처리

재질은 스프링강이 기본이며, 스프링용 스텐레스강은 주문 생산으로 대응합니다. 경도는 HRC 44~52, 표면처리는 인산피막처리(A.C.P)가 표준이며 요청 시 Zn 도금도 가능합니다.

※ 위 도면과 표는 SWS TECH 종합 카탈로그(스냅링 편, 12페이지)의 원본 PDF에서 직접 뽑은 것입니다 — 사진이 아니라 벡터 원본이라 해상도 제한이 없습니다. 처음에는 이 부분을 직접 그린 SVG 도면으로 대체했다가, 사진 속 "R팩" 그림을 "구멍 입구 모따기(R)"로 잘못 해석해 없는 치수를 만들어 넣는 오류가 있었는데, 원본 PDF로 다시 대조하며 바로잡았습니다 — R팩은 치수가 아니라 링을 여러 개 정렬해 테이프·밴드로 묶는 포장 방식입니다. 원본 PDF가 훨씬 선명해서 표 전체를 처음부터 다시 대조했고, 외경(d3)이 잘못 적혀 있던 R-8·R-10을 포함해 15개 사이즈를 고쳤으며, 누락된 Size No.39·46 행을 추가하고 존재하지 않는 Size No.31 행은 삭제했습니다. d3 공차와 두께(t)·t공차 열도 원본 표기 그대로 전부 다시 옮겼습니다 — 기존에 다른 자료(DIN 472 등)에서 가져온 비대칭 형식("+0.36/-0.10")은 이 SWS 원본의 대칭 형식("±0.18" 등)과 값 자체가 달라, 자사 카탈로그 표기인 SWS 원본 값으로 통일했습니다. 홈지름(d2)·공차등급 두 열은 SWS 카탈로그에는 없는 항목이라 이전 자료값을 그대로 유지했고, 새로 추가한 Size No.39·46 행은 그 두 값이 없어 "—"로 남겼습니다. Size No. 앞의 *(6~18, 39, 46, Size No.130 이상)은 SWS(유통사) 자체 규격, ○(40, 42, 45, 47, 48)은 구(舊) JIS 규격이라는 원본 카탈로그의 범례를 그대로 표기한 것입니다. 정밀 가공·발주 전에는 반드시 정식 KS B 1336 규격서 원본으로 최종 확인하시기 바랍니다.
